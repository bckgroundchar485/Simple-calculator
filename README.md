Simple Calculator
A simple calculator built using HTML, JavaScript, and divs/buttons. 
It supports basic arithmetic operations such as 
addition, subtraction, multiplication, and division.

Features
-Basic calculator functions
-Clean and simple interface
-Easy to use
-Works in a web browser

How to Run
-Open the project folder.
-Double-click index.html in your browser, or open it using a local web server.
-Use the calculator to do basic math operations.

Notes
This project is a beginner-friendly calculator made with simple web elements. 
It is useful for learning how to create interactive UI elements and handle button clicks with JavaScript.
